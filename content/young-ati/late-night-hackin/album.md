## Release Strategy

### Distribution Channels
1. **CLI music player** — `npx young-ati` (open-source, npm package, TUI interface)
2. **Terminal-styled website** — web mirror of CLI experience
3. **Spotify / Apple Music / YouTube Music** — via DistroKid
4. **GitHub** — README = album page, stars = listeners

### Release Timeline
- **Phase 0 (Weeks 1-3):** Singles blitz — drop a new single every 2-3 days on Spotify + social. Heavy promo on TikTok, X, Instagram, Reddit.
- **Phase 1 (Weeks 4-5):** CLI player launch + npm publish + HN "Show HN" post
- **Phase 2 (Weeks 5-16):** Sustained promo, full album on Spotify, targeted ads

### Lead Single
**New Terry Davis** — Terry Davis (TempleOS creator) is a hacker culture icon. The "love me or hate me" hook is the catchiest. 3 verses show depth. HN/tech Twitter catnip.

### Waterfall Singles Order
1. New Terry Davis (lead)

## Promo Strategy

- **Primary:** GitHub/npm (CLI player IS the distribution)
- **Secondary:** Hacker News, tech Twitter, r/startups, r/programming, Indie Hackers
- **Social:** TikTok/Reels 1-2x/day, X 3-4x/week, Instagram 3x/week
- **Paid:** $50-200/mo targeted FB/IG ads to founder/engineer profiles
- **Transparency:** Upfront about AI (Suno) production — "I write the lyrics, Suno is my producer"
